# 防災トラベルナビ（全国版）

現在地（またはGPSで選んだ行き先）に応じて、気象警報・雨量・土砂災害リスク・火山情報・地図を
表示する旅行者向け防災PWAです。鹿児島版と違い、**サーバー側の定期取得を持たず、ブラウザが
気象庁・国土地理院に直接アクセスします。** そのぶん常に最新の値が表示され、GitHub Actionsの
設定も不要です。

デザインは鹿児島版と同じ配色・レイアウト（白背景・赤ヘッダー・カード型UI）を踏襲しています。

## ファイル構成

```
index.html              アプリ本体（CSS・JSすべて同梱）
sw.js                    Service Worker（本体はcache first、気象庁への直接リクエストは素通り）
manifest.json            PWAマニフェスト
icon.svg                 アプリアイコン（仮のコンパスモチーフ。お好みで差し替えてください）
data/regions.json        全国64地域（気象庁の一次細分区域）の代表座標マスターデータ
data/volcanoes.json      主要な常時観測火山の座標マスターデータ（近くにある時だけ表示に使用）
```

## 導入手順

1. 新しいGitHubリポジトリを作成し、このフォルダの中身をルートに置く
2. Settings → Pages で公開（`main`ブランチ、`/`root）。**GitHub Actionsの設定は不要です**
3. スマホでアクセスし、位置情報の利用を許可する

地図タブは国土地理院タイルを使うため、APIキーの取得・設定は不要です（v1.1でGoogleマップ
Embed APIへの依存を廃止しました）。

## 仕組み

### 現在地の解決
GPSの緯度経度から、`data/regions.json`（気象庁の予報区64地域）の中で最も近い地域を選び、
その地域コードで気象庁に直接fetchします。気象庁のJSON API（予報・警報・アメダス）は
ブラウザから直接叩いてもCORSで弾かれないことを確認済みです。

雨量・風などの実況値は、気象庁が公開する全国約1300地点のアメダス観測点一覧
（`amedastable.json`）を一度だけ取得し、現在地から最も近い観測点を計算して使います。
特定の地点IDをアプリに埋め込む必要がないので、全国どこでも同じ仕組みで動きます。

### 地図・ハザードマップ
雨雲レーダー（気象庁タイル）とハザードマップ（国土地理院タイル）は、もともと座標ベースで
全国対応しているため、中心座標を現在地に変えるだけでそのまま動きます。鹿児島版で作った
「表示中の範囲をIndexedDBに保存してオフラインで見る」機能もそのまま使えます。

### オフライン対応
- **地図タイル**: 「雨量・台風」「土砂・火山」タブの「この範囲を保存」で、表示中の範囲を
  端末に保存できます（鹿児島版と同じ仕組み）。
- **気象データ**: 設定タブの「オフライン保存」で、地点ごとのデータをスナップショットとして
  端末に保存できます。保存方法は2通りです。
  - 「現在地を保存」— 今表示している位置（GPSまたは選んだ行き先）をそのまま保存
  - 「座標で地点を追加」— 緯度経度（またはGoogleマップのリンク）を直接指定して、
    今その場にいなくても、旅行予定地のデータを事前に取得・保存できます。地域名検索
    （64地域）より細かい座標を指定できるので、同じ予報区内でも実際に行く場所に近い
    アメダス観測点のデータを拾いやすくなります
  - 保存した地点は一覧から「表示」を押すといつでも呼び出せます（圏外でもOK）。表示中は
    現在地表示に「保存データ（オフライン）」の黄色いラベルが付き、他のタブもその地点を
    中心に表示されます
  - GPSでの取得に失敗した時は、保存済み地点の中から現在地に一番近いもの（80km以内）を
    自動的に表示にフォールバックします

## 鹿児島版から削除・簡略化した機能

サーバー側の定期取得に依存していた機能は、全国どこでも動く形にできないため、今回は
落としています。

- **月別降水量の平年値グラフ** — 64地域分の平年値データを持っていないため削除
- **過去の降水量集計（1ヶ月・3ヶ月）** — 気象庁の統計ページはJSONではなくHTML表で、
  全地域分をスクレイピングする定期処理が必要になるため削除。今日の実況（1h/3h/24h）は
  アメダスの実況値からそのまま出せるので残しています
- **先行7日雨量を使ったリスク補正** — 同上の理由でリスク計算式から外しています
- **避難所の一覧** — 鹿児島版は市の指定避難所を手打ちしていましたが、全国分のデータベースは
  持っていません。地図タブから「近くの避難所を探す」でGoogle検索に飛ぶ形にしています
- **公共交通の個別路線** — 地域ごとに運行会社が違うため、検出した都道府県のJR会社と
  Yahoo!路線情報へのリンクに簡略化しています
- **記録的短時間大雨情報** — 気象庁の防災情報XMLフィードを読む必要があり、JSON直取得より
  一段実装コストが高いため今回は見送りました

## 既知の制約・要確認事項

実際に動かして確認してほしい点です。

- **リスク計算式・警報コード表** — 鹿児島版から流用した簡易式です。実際のデータで一度
  動作確認をお願いします
- **屋久島・種子島は鹿児島本土と同じ地域（460100）** — これは気象庁の実際の予報区分と
  一致しているため誤りではありませんが、代表座標が鹿児島市のため「現在地」表示の距離が
  実際とずれます。予報・警報の内容自体は正しく、アメダスの実況値は最寄り観測点から
  別途計算されるので、体感としては大きな問題にはならないはずです
- **小笠原諸島など離島の一部** — `regions.json`に個別の区分がなく、遠く離れた地域に
  丸められてしまいます（テストでは静岡県に丸まりました）。利用者が少ない離島なので
  今回は見送りましたが、必要であれば個別に追加できます
- **アメダス最寄り観測点の判定** — 気温観測地点を優先しているため、降水量だけの
  簡易観測所より少し遠い地点を選ぶことがあります
- **JR会社の都道府県対応表** — 県境をまたぐ路線などの細かい例外は反映していません

## v1.1 での変更点

- **Googleマップ APIキーを廃止** — 地図タブは国土地理院タイル（無料・登録不要）を使う
  Leaflet地図に変更しました。現在地とスポットをマーカー表示します。ルート検索は、
  APIキー不要のGoogleマップのdeep link（`google.com/maps/dir/?api=1&...`）を開く方式に
  変更しています。ワンタップでGoogleマップアプリ／サイトに遷移して実際のナビができます
- **雨雲レーダーをアニメーション対応に** — 直近6コマを取得し、▶/⏸ボタンで再生できるように
  しました
- **右上の「更新」ボタンで自動的にオフライン保存** — 手動でスナップショットを保存しなくても、
  更新のたびに現在地のデータが自動的に上書き保存されます（一覧に「自動保存」と表示）。
  地図タイルの保存は従来通り明示的な操作のままです（通信量が大きいため）
- **時刻表・案内板の写真を保存できる機能を追加** — 地図タブに「時刻表・案内を保存」カードを
  追加。カメラロールから選ぶか、その場で撮影して保存できます（IndexedDB保存、圏外でも閲覧可）
- **カードの並び替え機能を追加** — ホーム／雨量・台風／土砂・火山／地図の各タブに
  「↕ 並び替え」ボタンを追加。押すと各カードに▲▼ボタンが出て、上下に移動できます。
  順序は端末に保存されます
- **交通機関リンクの修正** — JR東日本・JR東海・JR四国・Yahoo!路線情報のURLが古い／誤りだった
  ため修正しました（JR北海道・JR西日本・JR九州は確認の結果、問題ありませんでした）

## v1.2 での変更点

大阪防災アプリ（大阪府・Dawnコーポレーション提供）を参考に、以下を修正しました。

- **警報表示の不具合を修正** — 気象庁のデータに対応表未登録のコードが含まれる場合、
  「警報等()」のような空欄表示になっていたのを修正。該当データは除外し、
  警報がない場合は通常の「特別な警報なし」表示になります
- **火山カードに気象庁へのリンクを追加** — ホーム・土砂火山タブの両方に、該当の火山の
  位置にズームした気象庁の噴火警戒レベルページへのリンクを追加
- **おみやげリストの「買う場所」は未選択のまま保存可能**（元から対応済みでした）
- **リストの削除をスワイプ対応に** — おみやげ・スポット・オフライン保存地点のリストを
  左にスワイプすると削除できます（✕ボタンでの削除も引き続き使えます）
- **土砂・火山のリスク計算で現在地以外の地点も正しく反映** — これまでは地点を選んでも
  雨量データは常に現在地のものを使っていましたが、選択したスポットの最寄りアメダス観測点・
  警報を個別に取得して計算するようにしました
- **地図タブを1枚のカードに統合** — スポット表示とルート検索を同じカード内で切り替える
  形にし、スポット追加ボタンも地図のすぐ下に配置。地図自体の大きさ・縦横比は変更していません
- **非常持出袋チェックリストを削除**
- **クレジットカードを追加** — 気象庁・国土地理院・ハザードマップポータル・Leafletの
  データソースと公式リンクを設定タブに掲載

大阪防災アプリは市区町村住民向けの長期運用アプリのため、避難情報・避難所情報・熱中症警戒・
国民保護情報などは今回あえて実装していません。旅行者が必要とする直近1週間程度の情報に
絞る方針です。

## v1.2.1 での変更点

- **雨雲レーダーが表示されないバグを修正** — アプリ起動直後、気象データの取得が終わる前に
  「雨量・台風」タブを開く（前回見ていたタブが自動的に復元される場合を含む）と、雨雲の
  コマがまだ空の状態で地図が作られてしまい、後からデータが届いても重ね合わせが追加されない
  という不具合がありました。データが届いたタイミングで再度反映されるように修正しています

## v1.3.0 での変更点

雨雲レーダーをより「リアルタイム」で細かく見られるようにしました。

- **予報コマ（未来分）を追加** — これまでは過去6コマのみでしたが、気象庁の実況コマ
  （直近1時間・5分間隔）と予報コマ（この先の高解像度降水予報）の両方を取得し、
  1本の連続したタイムラインとして再生できるようにしました
- **「現在」の位置を明示** — 再生バーに縦線で「現在」の位置を表示し、左が実況（過去）、
  右が予報になります。時刻表示にも「実況」「現在」「予報」のラベルを付けています
- **表示中は自動更新** — 「雨量・台風」タブを開いている間、2分おきに最新のコマ一覧を
  確認し、新しいコマが来ていれば自動的に反映します（気象庁のナウキャストは5分更新）
